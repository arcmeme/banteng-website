# BANTENG Website

Simple React + Vite + Tailwind website for the $BANTENG meme token.

## How to run locally

1. Install dependencies
```bash
npm install
```

2. Run dev server
```bash
npm run dev
```

3. Build for production
```bash
npm run build
```

## Notes
- Replace contract address in `src/BantengLanding.jsx` (CONTRACT_ADDRESS variable).
- Buy link uses PancakeSwap with the CONTRACT_ADDRESS.
- Mascot image is in `public/assets/mascot.png`.
